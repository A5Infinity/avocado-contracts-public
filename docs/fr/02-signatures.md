# 2. Signatures et actions

Un forwarder reçoit une liste d’actions signées, vérifie l’autorisation EIP-712 puis les exécute pour le compte Avocado. L’ordre et le contenu des actions font partie du message authentifié.

Ce chapitre relie le mécanisme aux contrats concernés et explicite les invariants utiles à un intégrateur.
